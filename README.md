# Alyvera Agenda Hyperframes Base

Projeto base em `Hyperframes` para uma intro vertical da Alyvera usando o bloco `instagram-follow` como composicao principal.

## Scripts

- `npm run preview` abre o preview local no navegador
- `npm run lint` valida a estrutura da composicao
- `npm run render` gera `renders/alyvera-agenda.mp4`

## Estrutura

- `index.html`: host principal em `1080x1920`
- `compositions/instagram-follow.html`: composicao principal customizada para a Alyvera
- `assets/Alyvera_logo.png`: copia da logo usada no video
- `hyperframes.json`: configuracao de paths do Hyperframes
